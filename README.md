# かわさき Money Viewer

川崎市がPDFで公開している「補助・助成金一覧表」を予算・決算・年度別に検索し、一般会計当初予算の全体像も閲覧できる静的サイトです。

川崎市とは無関係の非公式サイトです。制度の内容、申請条件、募集状況などは川崎市の公式案内をご確認ください。

公開予定URL：<https://yama53-lab.github.io/kawasaki-money-viewer/>

## ローカルで確認する

Finderから `start-local-preview.command` をダブルクリックすると、ローカル確認用サーバーが起動し、一般会計ページがブラウザで開きます。

詳しい操作、終了方法、エラー時の対処は[ローカル確認の手順](LOCAL_PREVIEW.md)をご覧ください。HTMLファイルを直接開く `file://` ではJSONデータを読み込めないため、必ずこの手順で確認してください。

## 収録データ

- 予算：令和8年度〜平成19年度（20年度分）
- 決算：令和6年度〜平成17年度（20年度分）
- 合計40年度資料、約14,000件
- 一般会計：令和8年度〜平成25年度当初予算（14年度分、歳入・目的別歳出・性質別歳出・市民1人あたり）

各年度は独立したJSONファイルで管理しています。初期表示は令和6年度決算です。

## 主な機能

- 予算・決算の切り替え
- 同じ年度の予算額・決算額・予算差・執行率の比較（平成19年度〜令和6年度）
- 各項目の詳細で、収録年度すべての予算・決算を2本の縦棒で比較
- グラフの棒にマウス、キーボード、タップで触れたときの金額表示
- 対象年度の切り替え
- 補助金名、交付先、分類を対象にしたキーワード検索
- 所管局、交付先区分、金額、前年度比による絞り込み
- 当年度・前年度の金額と増減の比較
- 億円・万円による読みやすい金額表示と、原資料の千円単位の併記
- 金額、増減額、継続年数、掲載順による並び替え
- 選択中の年度に対応した川崎市公式PDFへのリンク
- 令和8年度〜平成25年度一般会計当初予算の年度切り替え
- 一般会計の概要、歳入（年度により22〜25項目）、目的別歳出16項目、性質別歳出、市民1人あたりの使いみち
- 歳入から一般会計、目的別歳出への全体構成を示すサンキー図
- スマートフォン・デスクトップ対応
- 予算・決算40年度分の検索エンジン向け年度別一覧ページ
- サイトマップ、正規URL、データセット構造化データ

平成21年度以前の予算と平成19年度以前の決算は、原資料に前年度額・継続年数・分類の掲載がないため、該当する比較・絞り込み項目を画面上で無効化します。

予算・決算比較では、補助・助成金名を正規化して一致する項目を対応付けます。名称が変更された項目や片方の資料だけに掲載された項目は自動的に同一視せず、「予算のみ」「決算のみ」として表示します。

## サイト案内ページ

- `general-account.html`：令和8年度〜平成25年度一般会計当初予算の全体像
- `about.html`：サイトの目的、非公式であること、収録範囲、抽出方法、更新方針
- `help.html`：検索・グラフの操作、件数の定義、予算差・執行率の計算、名称による比較の限界
- `policy.html`：正確性と再利用上の注意、検索語の扱い、アクセス解析・配信サービスの情報処理

各ページは検索ページのフッターから移動できます。説明ページはJavaScriptなしでも本文を読めます。

公開用ファイルの生成時には、各年度の名称・所管局・交付先・金額をHTMLで読める年度別一覧ページも自動生成します。検索・絞り込みは従来どおりトップページで利用できます。

## データの作成・更新方針

川崎市の最新年度・過年度ページに掲載されたPDFの表から名称・金額・交付先・所管局などを抽出し、年度別のJSONに整理しています。金額は原資料の千円単位を保持し、画面では億円・万円などの表示も併記します。

合計欄がある資料では抽出した明細の合計を照合しています。ただし、文字の誤読、項目の欠落、名称による比較の対応付けなどの誤りが生じる可能性があります。正確性・完全性・最新性を保証するものではありません。

データの更新は管理者が確認して行います。川崎市側の追加・訂正が即時に反映されるわけではありません。判断・引用・申請の前には、必ず原資料をご確認ください。

## 検索語・プライバシー

検索と絞り込みはブラウザ内で行い、検索語をサイトから外部へ送信したり保存したりしません。サイト独自のアクセス解析は導入していません。

配信サービス側での接続情報の取り扱いや外部リンクについては、サイト内の「利用上の注意・プライバシー」をご確認ください。

## 利用上の注意・再利用条件

川崎市への問い合わせにより、補助・助成金一覧表からの抽出・加工・比較表示とJSONデータの公開は可能で、事前の利用許諾申請などの手続きは不要との回答を得ています。

対象資料は、最新年度・過年度とも川崎市オープンデータ利用規約の適用対象ではありません。本サイトは今回の個別回答に基づいてデータを利用し、オープンデータのCCライセンスが適用されるものとしては扱いません。

川崎市に説明し、回答で確認された次の表示・案内を維持します。これらに加え、追加の条件や公開前の画面・データ例の提出は不要との回答です。

- 川崎市とは無関係の非公式サイトであること
- 出典と原資料へのリンク
- データ更新日
- 抽出誤りの可能性
- 申請条件や制度の最新情報は、公式資料・各所管局で確認すること

この確認は、本サイトの収録対象である補助・助成金一覧表の利用についてのものです。一般会計の表示に用いる予算資料など、川崎市の他の資料について同じ個別回答が適用されることを意味しません。また、本サイトの公式認定・内容の監修を意味するものではありません。数値やグラフを引用する際は、対象年度・予算／決算の区別・原資料へのリンクと、本サイトで抽出・加工したデータであることを明示してください。

サイトのコード・文章・ロゴと川崎市の元資料の利用条件は別です。サイト全体に一律のオープンライセンスを設定していません。一般的な著作権等の案内は[川崎市「著作権・リンク・免責事項」](https://www.city.kawasaki.jp/main/site_policy/0000000027.html)をご確認ください。
