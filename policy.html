01 / ACCURACY

正確性と原資料の確認

このサイトは、川崎市とは無関係の非公式サイトです。公式PDFの表からデータを機械的に抽出・整形しているため、文字の取り違え、金額の誤読、項目の欠落、比較の対応付けの誤りなどが生じる可能性があります。

合計額の照合などを行っていますが、正確性・完全性・最新性を保証するものではありません。資料の訂正や新しい年度の公表が、このサイトに未反映の場合もあります。

判断・引用・申請の前に、必ず原資料を確認してください。

検索ページのPDFリンクから、対象年度の名称・金額・交付先・所管局をご確認ください。制度の申請条件、募集状況、受給可否は、川崎市の公式案内と各所管局に確認してください。

このサイトの比較・グラフは情報を理解するための補助です。制度への評価や、支出の適否を判断するものではありません。

02 / REUSE

データの再利用条件

川崎市への問い合わせにより、補助・助成金一覧表からの抽出・加工・比較表示とJSONデータの公開は可能で、事前の利用許諾申請などの手続きは不要との回答を得ています。

対象資料は、最新年度・過年度とも川崎市オープンデータ利用規約の適用対象ではありません。本サイトは今回の個別回答に基づいてデータを利用し、オープンデータのCCライセンスが適用されるものとしては扱いません。

川崎市に説明し、回答で確認された次の表示・案内を維持します。これらに加え、追加の条件や公開前の画面・データ例の提出は不要との回答です。

  • 川崎市とは無関係の非公式サイトであること
  • 出典と原資料へのリンク
  • データ更新日
  • 抽出誤りの可能性
  • 申請条件や制度の最新情報は、公式資料・各所管局で確認すること

この確認は、本サイトの収録対象である補助・助成金一覧表の利用についてのものです。川崎市の他の資料の利用条件や、本サイトの公式認定・内容の監修を意味するものではありません。

数値やグラフを引用するときは、対象年度・予算／決算の区別・川崎市の原資料へのリンクを明示し、このサイトで抽出・加工したデータであることも記載してください。

サイトのプログラム・文章・ロゴと、川崎市の元資料の利用条件は別です。現在、サイト全体に一律のオープンライセンスを設定しているものではありません。一般的な著作権等の案内は次の公式ページをご確認ください。

  • 川崎市「著作権・リンク・免責事項」 ↗

03 / SEARCH PRIVACY

検索語の扱い

キーワード検索と条件による絞り込みは、読み込んだデータを使って、お使いのブラウザ内で処理します。入力した検索語を、このサイトの機能がサーバーや外部サービスへ送信することはありません。

検索語や絞り込み条件をURLに含めたり、運営者側の検索履歴として記録したりする機能もありません。ページを再読み込みすると条件は初期状態に戻ります。

ページの表示や年度の切り替え、グラフ表示では、サイトの配信元からHTML・画像・JSONなどを取得する通信が発生します。ブラウザや拡張機能など、このサイト以外の機能による情報の扱いは、それぞれの設定・方針に従います。

04 / ANALYTICS

アクセス解析・端末への保存

現在、このサイト独自のアクセス解析ツール、広告、行動追跡用のスクリプトは導入していません。アカウント登録や個人情報を入力するフォームもありません。

このサイトのプログラムは、検索履歴の保存や追跡のためにCookie・ローカルストレージを使用しません。ただし、ページやデータのブラウザキャッシュなど、通常の閲覧に伴う保存が行われる場合があります。

05 / HOSTING

配信サービス・外部リンク

GitHub Pagesで公開した場合、サイトの配信はGitHubのサービスを利用します。配信サービス側でIPアドレス、リクエスト日時などの接続情報が取り扱われる場合があります。「サイト独自のアクセス解析なし」は、配信サービス側の情報処理まで存在しないという意味ではありません。

GitHubの情報の取り扱いについては、GitHubのプライバシー声明 ↗をご確認ください。

川崎市の公式ページやPDFなど、外部リンクを開くと、そのサイトへの通信が発生します。移動先での情報の取り扱いには、移動先のプライバシー方針が適用されます。

06 / CHANGES

方針の変更

アクセス解析の導入や検索履歴の保存など、情報の取り扱いを変更する場合は、このページの内容と最終更新日を更新します。

データの作成・更新方針は「このサイト・データについて」、数字の計算方法や操作は「使い方・よくある質問」をご確認ください。
